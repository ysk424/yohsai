# Sample pattern

- `test3.pdf` — one-page Illustrator pattern used for Yohsai load / sewing / GRAVITY tests
  (OMOTE, URA, SODE, ERI). Rewritten with `pypdf` to drop unreferenced objects
  (~73 KB). **No character mesh** (CC assets stay local; not redistributable).

Default workflow: set Pattern Path to this file, Load, place panels, pick a local
Body mesh, then Zero / Normal GRAVITY.
